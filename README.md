# Portfolio site

This repository is configured for GitHub Pages and points its custom domain to [`goverco.me`](https://goverco.me) through [`CNAME`](./CNAME).

## Repository contents

The repository currently contains only the custom-domain configuration and this README; it does not contain the website source files. The site's source/deployment is managed elsewhere. Add the source or link its canonical repository here if you want this repository to be the single place to maintain the site.

## Domain configuration

Keep the `CNAME` file at the root of the Pages publishing source and ensure the domain's DNS records point to GitHub Pages. Do not change the domain or publishing settings without checking the live site and DNS first.
